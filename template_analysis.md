# Template Analysis and Selection

---

## Comparison Table

| Feature | Kanban | Team planning | Bug tracker |
|---------|--------|---------------|-------------|
| **Default Columns** | Backlog, Ready, In progress, In review, Done | Backlog, Ready, In progress, In review, Done | Todo, In progress, Done |
| **Automation Features** | None (manual movement) | None | None |
| **Workflow Suitability** | Visualizing workflow stages | Sprint planning with backlog | Tracking and fixing bugs |
| **Best For** | Continuous delivery, solo developers | Teams with sprint planning | Bug tracking teams |
| **Agile Methodology Support** | High (Kanban) | High (Scrum-like) | Low |

---

## Selected Template: Kanban

### Justification

I selected the **Kanban** template for Smart Campus Connect for the following reasons:

1. **Visual Workflow** - The columns (Backlog → Ready → In progress → In review → Done) clearly show each stage of work. This helps me track where each user story is in the development process.

2. **Simplicity for Solo Developer** - Unlike Team planning, the Kanban template has no complex automation. I can manually move issues as I work, which gives me full control.

3. **Alignment with Sprint 1** - My 7 user stories from Assignment 6 fit perfectly into the Backlog column. From there, I can move them to In progress when I start working, and to Done when completed.

4. **Customizable** - The template allows me to add columns like Testing and Blocked without breaking the workflow.

5. **Continuous Delivery Support** - Kanban boards are designed for continuous delivery, which matches my Agile approach of delivering working software incrementally.

### Why Not Other Templates

| Template | Reason for Rejection |
|----------|---------------------|
| **Team planning** | Designed for multiple team members with sprint planning meetings. As a solo developer, the extra structure would slow me down. |
| **Bug tracker** | Designed for bug reporting and fixing, not for user story management. The columns (Todo, In progress, Done) are too basic for my needs. |
