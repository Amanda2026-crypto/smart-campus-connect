## Selected Template: Automated Kanban

### Justification

I have selected the **Automated Kanban** template for Smart Campus Connect for the following reasons:

1. **Sprint Alignment** - Assignment 6 defined a 2-week Sprint 1 with 7 user stories. Automated Kanban is designed for sprint-based workflows.

2. **Automation Benefits** - When an issue is moved to "Done," it automatically closes. This reduces manual work for a solo developer.

3. **Simplicity** - Three core columns (Todo, In Progress, Done) keep the workflow focused. Additional columns can be added as needed.

4. **Traceability** - The 7 Sprint 1 user stories from Assignment 6 fit perfectly into this template.

5. **Future Sprints** - The template can be reused for Sprint 2, 3, and 4 without modification.

### Why Not Other Templates

| Template | Reason for Rejection |
|----------|---------------------|
| **Basic Kanban** | No automation features; would require manually closing each issue when completed |
| **Team Planning** | Too complex for a solo developer; unnecessary columns (Backlog, Ready, In Review) would cause confusion |
