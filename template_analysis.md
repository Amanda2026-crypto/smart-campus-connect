## Selected Template: Kanban

### Justification

I have selected the **Kanban** template for Smart Campus Connect for the following reasons:

1. **Automation** - This template auto-closes issues when moved to the Done column. For a solo developer, this saves time and ensures completed work is properly tracked.

2. **Sprint Alignment** - Assignment 6 defined a 2-week Sprint 1 with 7 user stories. The Todo → In Progress → Done workflow matches sprint stages perfectly.

3. **Simplicity** - Three core columns keep the workflow focused. Additional columns can be added as needed without breaking automation.

4. **Traceability** - The 7 Sprint 1 user stories from Assignment 6 fit perfectly into this template.

5. **Future Sprints** - The template can be reused for Sprint 2, 3, and 4.

### Why Not Other Templates

| Template | Reason for Rejection |
|----------|---------------------|
| **Team planning** | Too complex for a solo developer; unnecessary columns (Backlog, Ready, In Review) would cause confusion |
| **Bug tracker** | Designed for bug tracking, not user story management; no automation features |
