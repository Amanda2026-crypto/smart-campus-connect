## Challenges Faced

### 1. File Path Issues When Staging Changes

**The problem:** When trying to run `git add specific/file.py`, I got "pathspec did not match any files"

**How I solved it:** I used `dir /s filename.py` to locate the exact path first.

### 2. One PR Required Resubmission

**The problem:** My PR for Hospitality was initially closed without explanation.

**How I handled it:** I contacted the owner, asked for feedback, and resubmitted. It was eventually merged.

**Lesson learned:** Rejection is part of open source. Stay professional and try again.

### 3. Waiting for Reviews Takes Time

**The problem:** Reviews took days.

**How I handled it:** I followed up politely and learned to be patient.
